## 概要

**Synapsen Web** は、PC上で稼働している Synapsen (Nexus) のデータベースを、同一Wi-Fiネットワーク内のスマートフォン、タブレット、または他のPCから**閲覧・操作**するための軽量Webサーバーモジュールです。

PythonのマイクロWebフレームワークである **Flask** を使用して動作します。

### 主な特徴

* **レスポンシブデザイン:** スマートフォンやタブレットの画面サイズに最適化されたUIで、快適に閲覧できます。
* **Inbox Upload (アップロード):**
  * スマートフォンや他のPCから、Synapsenの「監視フォルダ (Inbox)」へ直接ファイルをアップロードできます。
  * 外出先で撮影した写真やPDF資料を、PCの前に座ることなく正規化フロー（Watchdog）へ投入可能です。
  * 複数ファイルの一括アップロードにも対応しています。
* **Nexus互換の検索:** Nexusと同じ検索構文（`tag:`, `date:`, `fulltext:` など）を使用して、データベースを検索できます。
* **PDF閲覧:** ノートに紐付いたPDFファイルをブラウザ上で直接開くことができます（該当ページへのジャンプ機能付き）。
* **Serendipity (偶然の発見):** 「🎲 Random Jump」機能により、過去のノートをランダムに表示し、予期せぬアイデアの再発見を促します。
* **Tag List:**
  * ノートに付与されているタグを一覧で確認する事が出来ます。
  * 「件数順（頻出タグ）」や「名前順（辞書順）」で並び替えができ、データベース全体の傾向を俯瞰できます。
  * タグをクリックすると、検索に移行します。
* **セキュリティ:** Basic認証により、アクセスを制限します。

## セットアップと有効化

Synapsen Web は、デフォルトでは「無効（隠し機能）」になっています。
利用するには、以下の手順でライブラリの導入と有効化が必要です。

### 1. 依存ライブラリ (Flask) のインストール

本機能は外部ライブラリ `Flask` を使用します。これらは Synapsen 本体の必須要件には含まれていないため、別途インストールが必要です。<br>
`pip install Flask`を使用するか、コマンドプロンプトで Synapsenのルートフォルダを開き、以下のコマンドを実行してください。

```bash
poetry install --no-root --extras web
```

### 2. 設定ファイルの編集

Synapsenのルートフォルダにある `config.ini` をテキストエディタで開き、以下の設定を行ってください。

#### A. Webサーバーの有効化
末尾に以下のセクションを追記（または編集）します。

```ini
; ------------------------------------------------------------------------------
; [Network] ネットワーク機能設定 (上級者向け)
; ------------------------------------------------------------------------------
[Network]
; Webサーバーモード（スマホ連携）ボタンをランチャーに表示するか (true/false)
; ※ セキュリティリスクを理解した上で有効にしてください。
enable_server = true
```

#### B. アップロード先の指定 (重要)
アップロード機能を使用するには、`[Watchdog]` セクションの `watch_dir`（監視フォルダ）が正しく設定されている必要があります。

```ini
[Watchdog]
; 監視するフォルダ
watch_dir = C:\Users\YourName\Downloads\Inbox
; 正規化済みファイルの出力先
output_dir = C:\Users\YourName\Documents\Normalized
; 正規化するサイズ (A4 または A5)
target_size = A4

```

### 3. ランチャーの再起動

`config.ini` を保存した後、Synapsen ランチャーを再起動すると、メニューに **「Web Server (錆浅葱色)」** のボタンが表示されます。

## 使い方

1.  **準備:** ファイルの自動処理を行うため、PC上で **`Run_Watchdog.bat`** (常駐監視) を起動しておきます。
2.  ランチャーの「Web Server」ボタンをクリックします。
3.  黒いコンソール画面（コマンドプロンプト）が立ち上がり、サーバーが起動します。
    ```text
    ==================================================
     Synapsen Web Server Running...
     Access URL: [http://0.0.0.0:5000/](http://0.0.0.0:5000/)
    ==================================================
    ```
4.  **PCから見る場合:** ブラウザで `http://localhost:5000/` にアクセスします。
5.  **スマホから見る場合:**
    * PCのIPアドレスを確認します（コマンドプロンプトで `ipconfig` を実行し、IPv4アドレスを確認。例: `192.168.1.15`）。
    * スマホのブラウザで `http://192.168.1.15:5000/` にアクセスします。

### アップロード機能の使い方
1.  メニューバーの **「Upload」** をタップします。
2.  「ファイルを選択」ボタンを押し、カメラで撮影した写真やPDFファイルを選択します（複数選択可）。
3.  「アップロード開始」ボタンを押します。
4.  ファイルがPCの `watch_dir` に転送されます。`Run_Watchdog.bat` が起動していれば、即座に正規化（サイズ統一・OCR等）が行われ、Inboxへ格納されます。

### 認証について (ログイン)

初回アクセス時に、ユーザー名とパスワードが求められます。

* **デフォルトユーザー名:** `admin`
* **デフォルトパスワード:** `password`

> **⚠️ 重要: パスワードの変更方法**
> ファイルのアップロードが可能になったため、**セキュリティの重要性が高まっています。** 必ずパスワードを変更してください。
> `Synapsen_Web/server.py` ファイルをテキストエディタで開き、以下の部分を書き換えてください。
>
> ```python
> # --- 認証設定 ---
> USERNAME = "admin"      # ← ここを好きなユーザー名に変更
> PASSWORD = "password"   # ← ここを複雑なパスワードに変更
> ```

## トラブルシューティング

### Q. スマホから繋がりません (タイムアウトする)

Windowsのファイアウォール設定が原因である可能性が高いです。

1.  **ネットワーク設定の確認:**
    * PCのWi-Fi設定を開き、接続中のネットワークプロファイルが「パブリック」になっていないか確認してください。「**プライベート**」に変更することで解決する場合があります。
2.  **ファイアウォールの許可:**
    * セキュリティソフト（ESET, Norton, Windows Defender等）の設定で、ポート `5000` (TCP) の受信を許可するか、`Synapsen.exe` (または `python.exe`) の通信を許可してください。
3.  **IPアドレスの確認:**
    * PCのIPアドレスが変わっている可能性があります。`ipconfig` で再確認してください。

### Q. アップロード時にエラーになる

1.  **フォルダ設定:** `config.ini` の `watch_dir` パスが存在するか確認してください。
2.  **ファイルサイズ:** 極端に大きなファイル（数百MB以上）は、サーバーの設定やメモリ制限により失敗する場合があります。
3.  **Watchdog:** アップロード自体は成功しても、その後の正規化が行われない場合は、PC上で `Run_Watchdog.bat` が起動しているか確認してください。
